# Zitate-App

Diese iOS-App präsentiert inspirierende, motivierende und andere Zitate vor wechselnden Hintergrundbildern. Benutzer können Zitate nach Kategorien filtern, neue zufällige Zitate anzeigen lassen und ihre Lieblingszitate als Favoriten markieren.

## Funktionen

* **Zufällige Zitate:**  Zeigt zufällige Zitate aus einer Sammlung an.
* **Hintergrundbilder:**  Verwendet wechselnde Hintergrundbilder, um die Zitate visuell ansprechend zu präsentieren.
* **Kategoriefilter:**  Ermöglicht das Filtern von Zitaten nach Kategorien (z.B. Inspirierend, Motivierend, Lebensweisheit, Glaube).
* **Favoriten:**  Benutzer können Zitate als Favoriten markieren, um sie später leicht wiederzufinden.
* **Favoritenansicht:** Eine spezielle Ansicht zeigt alle favorisierten Zitate an.
* **Zitat teilen:** (Optional - falls implementiert) Ermöglicht das Teilen von Zitaten über soziale Medien oder andere Plattformen.

## Technologien

* **SwiftUI:**  Die App ist komplett in SwiftUI entwickelt.
* **SwiftData:**  Verwendet SwiftData für die persistente Speicherung der Zitate und Favoriten.

## Installation

1. Klonen Sie das Repository: `git clone https://github.com/[your-github-username]/ZitateApp.git` (Ersetzen Sie `[your-github-username]` durch Ihren GitHub-Benutzernamen).
2. Öffnen Sie das Projekt in Xcode.
3. Wählen Sie ein Ziel (Simulator oder physisches Gerät) und führen Sie die App aus.

## Verwendung

1. **Startbildschirm:**  Ein zufälliges Zitat wird zusammen mit einem Hintergrundbild angezeigt.
2. **Kategorieauswahl:**  Verwenden Sie den Picker, um Zitate nach Kategorie zu filtern oder alle Zitate anzuzeigen.
3. **Neues Zitat:**  Tippen Sie auf die Schaltfläche "Neues Zitat", um ein neues zufälliges Zitat zu laden.
4. **Favoriten:**  Tippen Sie auf das Herzsymbol, um ein Zitat als Favoriten zu markieren oder zu entfernen.
5. **Favoritenansicht:**  Tippen Sie auf die Schaltfläche "Favoriten", um eine Liste aller Ihrer favorisierten Zitate anzuzeigen.
6. **Zitat löschen:** In der Favoritenansicht können Sie Zitate durch Wischen nach links entfernen.


## Zukünftige Erweiterungen

* **Mehr Zitate:**  Hinzufügen weiterer Zitate zu verschiedenen Kategorien.
* **Zitat teilen:**  Implementierung einer Funktion zum Teilen von Zitaten.
* **Benutzerdefinierte Kategorien:**  Ermöglichen es Benutzern, eigene Kategorien zu erstellen.
* **Offline-Modus:**  Sicherstellen, dass die App auch ohne Internetverbindung funktioniert (z.B. durch Caching der Zitate).
* **Verbesserte Benutzeroberfläche:**  Weitere Verbesserungen an der UI/UX, z.B. Animationen oder anpassbare Designs.
